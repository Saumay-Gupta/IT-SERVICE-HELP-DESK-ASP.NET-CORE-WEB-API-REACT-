# IT Service Request Management System

A full-stack IT Service Request Management System built using **ASP.NET Core Web API** and **React**.

## Technologies Used

- ASP.NET Core Web API
- Entity Framework Core
- SQLite
- React
- Axios
- Bootstrap

## Features

- User authentication
- Create and manage service requests
- Track request status
- Close service requests
- RESTful Web API
- Layered architecture with DAL, Repository, Service, DTO, and API layers

## Project Structure

- **Service Layer** – Web API and controllers
- **Data Access Layer** – Data access and repositories
- **React Frontend** – User interface
